# Integración React + GraphQL + Node.js + MySQL

Proyecto fullstack desarrollado como parte del taller de integración de APIs GraphQL con bases de datos relacionales y clientes React.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Node.js, Express, GraphQL (`express-graphql`), MySQL (`mysql2`), CORS.
* **Frontend:** React, Vite, Apollo Client (`@apollo/client`), CSS3 (Grid & Flexbox).
* **Base de Datos:** MySQL (XAMPP).

---

## 🚀 Instrucciones de Ejecución

### 1. Base de Datos (MySQL / XAMPP)
1. Iniciar los servicios de **Apache** y **MySQL** en XAMPP.
2. Ingresar a `phpMyAdmin` y ejecutar el script SQL para crear la base de datos `taller_graphql` y la tabla `usuarios`.
